TASK DESCRIPTION

The E-Commerce Market (Multi-Vendor) is a full-stack web application developed to provide an online shopping platform where multiple sellers can register, manage their products, and sell them to customers through a single website. The main aim of this project is to create a simple, user-friendly, and efficient online marketplace that connects customers, sellers, and administrators. It helps users purchase products online and enables sellers to manage their business activities digitally.
This project is developed using Python Flask for backend development, SQLite for database management, and HTML, CSS, and JavaScript for frontend development. Visual Studio Code is used as the development environment, and GitHub is used for source code management and project sharing. These technologies work together to provide a functional and interactive web application.
The application provides three main user roles: customer, seller, and administrator. Customers can register, log in, browse available products, search for items, add products to their shopping cart, update quantities, place orders, and view their order history. The shopping cart helps customers organize their selected products before checkout and makes the purchasing process easier.
Sellers can create accounts and submit them for administrator approval. After approval, sellers can access their dashboard and manage their own products. They can add new products, update product details, set prices, and manage available stock quantities. Sellers can also view orders related to their products. These features help sellers maintain their product information and manage their online business activities efficiently.
The administrator is responsible for managing the marketplace. The administrator can review and approve seller accounts and update order statuses. This functionality provides basic control over seller registration and order processing. Role-based access ensures that customers, sellers, and administrators can access the features intended for their roles.
The application uses an SQLite database to store user details, product information, shopping cart data, and order records. Flask handles requests between the frontend and backend, processes user actions, and communicates with the database. JavaScript supports interactive frontend behavior, while CSS provides the styling and layout of the website.
The major benefits of this project include convenient online shopping, centralized product management, support for multiple sellers, organized order processing, and a simple user interface. It also provides practical experience in full-stack web development, database connectivity, authentication, session management, CRUD operations, and role-based access control.
In the future, this project can be enhanced by integrating secure online payment gateways, product reviews and ratings, product image uploads, delivery tracking, email notifications, sales reports, and advanced search and filtering options. Additional security improvements and responsive design enhancements can also make the application more suitable for real-world use.
Overall, the E-Commerce Market (Multi-Vendor) project demonstrates how frontend technologies, backend development, and database management can be combined to build an online marketplace. It is a useful academic project for understanding full-stack web development and provides a foundation for developing a more advanced e-commerce platform.
